## 一、项目概述
### 1.1 项目背景
本项目为个人自用的AI投研辅助工具，源于个人投资实践与多次同类项目的经验复盘。过往项目普遍存在「分析无沉淀、判断无验证、错误无归因、能力无积累」的痛点：分析结论产出后即流失，无法追溯当时的判断逻辑；判断对错仅凭感觉，无法系统性复盘偏差原因；工具始终停留在「一次性问答」层面，不会随着使用频次增加而变得更好用。

基于此，本项目以「标准化分析流程 + 自动化任务执行 + 全链路判断闭环」为核心，参考成熟金融分析方法论重建分析能力，将重复的投研工作流水线化、自动化，同时建立「判断记录-走势验证-偏差归因-人工迭代」的完整闭环，让工具的分析能力可沉淀、可验证、可优化，真正成为长期可用的个人投资辅助系统。

### 1.2 项目目标
构建一套**盘后运行、自动执行、人工决策、持续迭代**的个人炒股智能辅助系统：
1.  自动化完成股票筛选、深度分析、持仓跟踪、异动预警等重复性投研工作，降低日常研究成本；
2.  以标准化分析方法论输出结构化、可溯源的分析结论，为买卖决策提供稳定的参考依据；
3.  自动跟踪历史判断与实际走势的偏差，标准化归因差异原因，辅助持续优化分析方法；
4.  采用「原子能力+流水线编排」的可扩展架构，支撑后续场景的持续扩充，越用越完善。

## 二、核心定位
### 2.1 项目是什么
- 一套**自动化盘后投研流水线系统**：按预设规则定时/触发式执行分析任务，批量产出标准化结果；
- 一个**个人投资决策辅助工具**：输出分析结论、持仓建议与风险提示，最终买卖决策完全由人工做出；
- 一套**判断复盘与能力沉淀体系**：完整记录所有分析判断，自动验证结果、归因偏差，支撑分析能力的持续迭代；
- 一个**可扩展的AI金融分析平台**：底层能力单元化建设，后续可通过编排组合快速落地新的分析场景。

### 2.2 项目不是什么
- 不是量化交易系统，不做高频交易、不进行自动下单；
- 不是实时行情软件，不追求盘中分钟级数据与实时预警；
- 不是通用投顾产品，不对外提供投资建议、不商业化；
- 不是「AI写研报」工具，不以产出报告数量为目标，核心价值在于判断的可验证与可迭代；
- 不是全自动自我进化的黑盒系统，所有分析方法的调整都由人工主导，系统仅提供数据支撑与归因辅助。

### 2.3 核心差异
| 维度 | 普通AI炒股工具 | 本项目 |
|---|---|---|
| 运行模式 | 人工提问、单次应答 | 流水线自动运行、批量产出结果 |
| 分析逻辑 | 自由问答、随机发挥 | 基于成熟方法论的标准化流程 |
| 记忆体系 | 仅保留对话历史 | 全量结构化存储判断、报告、归因结果 |
| 验证机制 | 无对错校验 | 自动匹配真实走势，量化判断效果 |
| 优化方式 | 人工调整Prompt | 偏差标准化归因 + 人工迭代方法 + 效果可对比 |
| 扩展能力 | 新增场景需重新开发 | 原子能力复用，流水线编排快速落地新场景 |

## 三、整体设计思想：原子能力 + 流水线编排
为支撑「当前三条核心场景 + 后续持续扩展更多流程」的需求，项目采用「底层原子能力单元 + 上层场景化流水线」的分层架构设计，兼顾落地效率与长期扩展性。

### 核心逻辑
1.  **底层：原子能力单元**
    将金融分析的各项动作拆解为独立、可复用的最小能力单元（如财务质量分析、估值分位计算、技术趋势判断、公告事件解读等）。每个单元对应一套标准化的分析方法、数据依赖与输出规范，是构成所有业务场景的「积木」。
    能力单元参考成熟金融分析插件的方法论移植建设，保证分析逻辑的专业性，同时与数据源解耦，可独立迭代、验证与版本管理。

2.  **上层：场景化流水线**
    针对具体业务场景，将多个原子能力单元按固定流程、规则和顺序编排组合，形成一条可自动执行的流水线。流水线可配置触发条件（定时触发/事件触发）、输入范围、输出格式，运行时按流程自动调用数据、执行分析、产出结果。

### 扩展优势
- 新增业务场景时，无需从零开发，仅需复用已有原子能力、调整编排流程即可快速落地；
- 能力单元的优化可同步惠及所有使用该单元的流水线，实现「一处优化、全场景生效」；
- 符合单人开发的节奏：首期落地核心流水线与高频能力单元，后续逐步扩充能力与场景，控制复杂度。

## 四、核心能力体系
### 4.1 底层原子能力单元
按功能类别划分为六大类，覆盖分析、决策、验证全流程所需的基础能力：

| 能力类别 | 包含核心单元 | 作用 |
|---|---|---|
| 基础数据类 | 行情数据获取、财务数据提取、公告数据拉取、行业指数匹配、数据质量校验 | 为所有分析提供标准化、可溯源的数据输入，统一数据口径 |
| 基本面分析类 | 业务概况速览、财务质量评估、估值水平与分位计算、成长性分析、盈利能力分析、同业对比 | 完成个股基本面维度的标准化研判 |
| 技术面分析类 | 趋势判断、关键价位计算（支撑/压力/止损）、量价分析、技术指标研判、相对强度分析 | 完成价格走势与交易层面的分析 |
| 事件资金类 | 异动归因、公告事件解读、资金面分析（两融/主力资金）、解禁/分红等事件影响评估 | 解析事件与资金面对股价的影响。注：北向资金个股/行业明细已于 2024-08 停止披露，原「北向资金分析」单元以融资融券 + 主力资金流向替代 |
| 决策辅助类 | 多空逻辑对撞、核心结论生成、交易条件建议、风险提示输出 | 整合多维度分析，输出明确的参考结论 |
| 验证归因类 | 判断匹配校验、走势基准对比、偏差程度计算、多维度归因分析、效果统计 | 支撑历史判断的验证、复盘与迭代 |

### 4.2 核心业务流水线（首期落地）
围绕最高频的三个核心场景，建设三条基础流水线，覆盖「选股-持仓-复盘」的完整个人投资链路。

#### 流水线1：标的发现与深度筛选流水线
- **触发方式**：每日盘后定时自动执行
- **执行流程**：
    1.  全市场量化初筛：按预设的基本面、技术面、流动性规则，批量筛选出基础候选池；
    2.  硬伤剔除：快速排查财务异常、高风险标的，收缩至重点分析池；
    3.  全链路分析：对重点池标的调用多维度原子能力，生成完整分析报告；
    4.  综合排序：按预设评分规则对标的排序，输出最终候选股票池。
- **输出产物**：每日候选股票池（Top N）+ 单只个股全链路分析报告 + 结构化判断结论。

#### 流水线2：持仓跟踪与异动分析流水线
- **触发方式**：每日盘后定时自动执行 + 事件触发
- **执行流程**：
    1.  日常持仓简报：批量拉取所有持仓股的行情、估值、技术位数据，生成每日持仓概览；
    2.  异动检测：校验价格、事件、资金三类异动条件，判断是否需要深度分析；
    3.  异动深度分析：对触发异动的标的，调用事件归因、逻辑校验等能力，分析异动原因与影响；
    4.  持仓建议输出：评估原持仓逻辑是否成立，给出继续持有/减仓/卖出的参考建议与观察条件。
- **输出产物**：每日持仓简报 + 异动个股深度分析报告 + 更新后的持仓判断结论。

#### 流水线3：判断验证与偏差归因流水线
- **触发方式**：每日盘后自动巡检 + 判断到期自动触发
- **执行流程**：
    1.  判断匹配：拉取历史未完成的结构化判断，与最新走势、基准指数做对比；
    2.  偏差检测：校验价位偏离、方向偏离、逻辑失效、到期验证四类偏差条件；
    3.  标准化归因：按「系统性因素-事件因素-基本面因素-技术面因素-方法因素」的固定流程拆解偏差原因；
    4.  结论更新：生成偏差归因报告，同步输出更新后的分析判断，关联存档。
- **输出产物**：偏差归因报告 + 更新后的分析结论 + 判断结果归档记录。

### 4.3 可扩展流水线方向
基于原子能力架构，后续可快速扩展更多场景化流水线，覆盖更全面的投研需求，例如：
1.  **定期全景复盘流水线**：每周/每月自动执行，汇总周期内选股效果、持仓表现、判断命中率，生成整体复盘报告；
2.  **财报季专项分析流水线**：财报披露期自动跟踪持仓与候选股的财报发布，批量生成财报解读与业绩影响评估；
3.  **行业板块监控流水线**：定期跟踪主流行业/板块的景气度、资金流向、轮动趋势，辅助赛道选择；
4.  **组合风险巡检流水线**：定期检查持仓组合的行业集中度、估值集中度、相关性风险，输出风险提示；
5.  **事件驱动筛选流水线**：针对特定事件（如回购、分红、业绩预告），自动筛选符合条件的标的并做初步分析。

## 五、核心运行机制
### 5.1 结构化判断存档机制
所有分析报告必须同步输出结构化的判断结论，与报告一同永久存档。判断结论包含明确的方向、有效期、关键价位、核心逻辑标签与分析方法版本，作为后续验证、归因、统计的基础。所有历史记录不可删除、不可篡改，仅可标注失效，保证复盘的真实性与完整性。

### 5.2 全链路版本管理机制
对筛选规则、分析方法、能力单元、流水线流程全部实行版本化管理：
- 每次调整均生成新版本，保留变更记录；
- 所有分析报告与判断结论均绑定对应版本号；
- 支持按版本统计判断效果，直观对比迭代前后的质量变化。

### 5.3 偏差标准化归因机制
所有判断偏差均遵循固定流程归因，避免AI自由发挥导致的结果不可靠：
1.  先定量拆解：拆分市场、行业、个股的收益贡献，区分系统性波动与个股自身差异；
2.  再排查外因：核对周期内的公告、事件、政策、资金变化；
3.  最后定位内因：排除外部因素后，对应到具体分析维度的方法缺陷。
    归因结果必须关联到具体的能力单元与分析维度，为人工迭代提供明确的优化方向；
    外因排查仅消费已落库的结构化事件表（公告/业绩预告/解禁/质押等，M2 建设完成），事件数据缺失的判断，归因报告必须显式标注「外因不可归因」，禁止 LLM 基于猜测补全外因。

### 5.4 人工主导的能力迭代机制
系统不自动修改分析规则，所有能力迭代均由人工主导，系统提供支撑：
1.  系统按维度、按版本统计判断胜率、偏差分布，暴露高频出错的环节；
2.  人工基于统计数据与归因结果，调整分析方法、筛选规则或流程；
3.  新版本上线后，系统持续跟踪运行效果，对比新旧版本的表现差异；
4.  人工确认优化有效后，新版本正式生效，否则回滚至旧版本。

### 5.5 数据质量保障机制
建立统一的数据校验规则，所有输入分析的数据必须经过质量检查：
- 数据缺失、过期、异常必须显式标注，禁止静默忽略或编造；
- 所有分析结论均可追溯到对应的数据来源与获取时间；
- 关键数据异常时，自动降级分析深度并提示风险，避免基于错误数据产出结论。

## 六、范围与边界约束
### 6.1 明确不做的事项
1.  不做盘中实时行情与分钟级分析，所有任务均基于收盘后日级数据运行；
2.  不对接券商账户、不执行自动下单，所有交易操作由人工完成；
3.  不对外提供投资建议、不商业化、不做多用户体系；
4.  不做全自动自我修改，所有分析规则的调整必须经过人工确认；
5.  不追求行情软件的全面性与展示效果，聚焦分析与复盘核心价值；
6.  不做收益承诺、不夸大分析效果，所有判断效果均以真实统计为准。

### 6.2 核心约束条件
1.  **数据约束**：基础数据源为Tushare日级数据；外因事件仅使用 Tushare 结构化事件接口（公告/业绩预告/解禁/质押等，均在 41 表范围内），新闻快讯类非结构化数据源 M1~M3 不引入，如后续引入须先登记数据源与运行成本；
2.  **开发约束**：单人开发、单人维护，所有设计优先控制复杂度，保证长期可维护性；
3.  **使用约束**：核心使用场景为盘后与周末，不追求盘中响应速度；
4.  **成本约束**：日常运行成本（模型调用、数据服务）控制在个人可接受范围内，优先复用免费/已购资源。

## 七、里程碑规划
遵循「先做深核心链路，再逐步扩展场景」的节奏，分四个阶段落地。

> 预期管理：M3 效果统计上线之前，系统判断的正确率未经统计验证，所有分析结论仅供研究参考——这正是 M3/M4 闭环要回答的问题。

### M1：基础能力搭建与选股流水线落地
- 完成核心原子能力单元建设（基本面、技术面、估值等高频能力）；
- 落地「标的发现与深度筛选流水线」，每日自动产出候选股票池与分析报告；
- 完成基础数据层对接与数据质量校验机制；
- 支持对任意标的发起手动单股深度分析（走触发表，仅执行分析阶段），闭环「偶发查证」使用场景；
- 验收标准：每日盘后可自动生成带结构化结论的个股分析报告，数据可溯源；查证任意股票可获得分析结论或明确的历史淘汰原因。

### M2：持仓跟踪与异动分析流水线落地
- 完成持仓管理、异动检测、事件分析类能力单元；
- 落地「持仓跟踪与异动分析流水线」，支持每日持仓简报与异动深度分析；
- 建立报告与判断的统一存档体系；
- 验收标准：录入持仓后，每日自动生成持仓复盘内容，异动标的自动产出深度分析与持有建议。

### M3：判断验证与归因闭环落地
- 完成验证、归因类能力单元建设；
- 落地「判断验证与偏差归因流水线」，实现判断自动校验与标准化归因；
- 完成版本管理与基础效果统计功能；
- 验收标准：历史判断可自动匹配走势，偏差自动生成归因报告，可按维度查看判断统计数据。

### M4：扩展能力与迭代体系完善
- 扩充更多原子能力单元，落地1-2条扩展流水线（如周度复盘、财报专项）；
- 完善版本对比、效果量化评估体系，支撑人工高效迭代；
- 优化流水线配置能力，降低新增场景的开发成本；
- 验收标准：可快速新增分析场景，迭代前后的效果可量化对比，系统分析质量有可观测的提升。

---

## 八、项目核心原则
1.  **流水线优先**：所有高频重复工作都尽量做成自动流水线，减少人工操作成本；
2.  **标准化优先**：分析流程、判断结构、归因逻辑全部标准化，降低随机性，保证可验证、可迭代；
3.  **人工决策闸门**：系统只输出参考建议，所有买卖决策与规则调整由人工最终确认；
4.  **诚实可验证**：所有判断、结果、偏差都真实展示，不美化、不隐瞒，样本不足明确标注；
5.  **渐进式扩展**：先跑透核心链路，再逐步新增场景，避免初期复杂度失控；
6.  **能力可沉淀**：所有分析方法都沉淀为可复用的能力单元，成为项目的长期资产，而非一次性代码。

---

## 九、项目价值总结
本项目兼具**投资实用价值**与**工程实践价值**：
- 对个人投资而言，它将重复的投研工作自动化，用标准化方法提升分析稳定性，同时通过闭环复盘机制持续优化判断质量，真正成为越用越好用的投资辅助工具；
- 对工程实践而言，它是一次完整的「AI+领域知识」应用落地实践，涵盖了能力沉淀、流程自动化、闭环验证、持续迭代等AI应用的核心工程问题。
